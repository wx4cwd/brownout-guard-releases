# Brownout Guard

A web page, phone alerts and safe shutdowns for UPSes, on a Raspberry Pi.

Install or update on the Pi (Raspberry Pi OS):

```
curl -fsSL https://github.com/wx4cwd/brownout-guard-releases/releases/latest/download/install.sh | sudo bash
```

Then open `http://<the Pi's address>:8494`.

This repository holds only the install files.
